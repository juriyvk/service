# Проверка перед тестовым развёртыванием

Дата: 2026-11-12 UTC. Ветка: `feat/secure-crm-core`, PR #1.

Проверен существующий публичный адрес Supabase, указанный в исходном Mini App. Запросы не содержали действительных Telegram credentials, ключей Supabase, персональных данных или webhook secret; база и конфигурация не менялись. Тела ответов с данными пользователей не сохранялись.

| Запрос | Результат |
| --- | --- |
| POST telegram-auth, пустой JSON | HTTP 400 |
| POST telegram-auth, заведомо некорректный initData | HTTP 401 |
| POST crm, snapshot без initData | HTTP 404 NOT_FOUND |
| POST telegram-webhook без secret | HTTP 404 NOT_FOUND |

Текущая функция входа отклоняет проверенные некорректные запросы. Это не подтверждает реализацию HMAC, срока действия, реестра сотрудников или модель ролей: для этого нужны действующий исходник и staging-проверки. Новые endpoints пока не развёрнуты; их 404 не является проверкой нового контроля доступа.

Проверки ядра, типов и браузерного сценария выполнены; добавлен отдельный набор тестов совместимости UUID и закрытого legacy-реестра. Они не заменяют живой Supabase/Telegram.

## Результат предоставленного read-only отчёта

Дата получения: 13 ноября 2026, московское время. Персональные строки сотрудников в отчёте отсутствуют.

- `public.employees.id`: UUID (виден в начале columns).
- `roles`: manager и deputy, по одной записи, обе активны.
- `duplicate_telegram_groups.count`: 0.
- `rls`: enabled=true, forced=false. Отсутствие FORCE RLS не открывает таблицу клиентам: владельцы и BYPASSRLS-роли могут обходить RLS; это требуется серверным функциям.
- `policies`, `table_grants`, `column_grants`: пустые массивы для проверенных объектов/ролей. В пределах этого отчёта прямой браузерный доступ не предоставлен.

Следующий этап: отдельный staging-проект, восстановление только структуры legacy-таблицы и синтетических данных, обе миграции и проверка настоящего Supabase Runtime/Storage. Действующие production-записи не переносить в автоматические тесты. Для deploy нужен отдельно настроенный защищённый доступ к Supabase; установка GitHub Connector его не предоставляет.
